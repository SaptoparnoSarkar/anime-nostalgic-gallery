# 🎌 Anime Nostalgia Gallery

A modern, animated web gallery that showcases timeless anime classics in a visually immersive way.
Built to evoke nostalgia while demonstrating clean frontend architecture and smooth UI interactions.

---

## 🧱 Tech Stack

### Frontend

* **React** – Component-based UI architecture
* **Vite** – Lightning-fast development and optimized builds
* **Tailwind CSS** – Utility-first styling
* **shadcn/ui** – Accessible, reusable UI components
* **Framer Motion** – Fluid animations and transitions

### Backend

* **Node.js** – Runtime for handling server-side logic

---

## ✨ Features

* ⚡ Fast build and hot module reload (Vite)
* 🎨 Modern UI components (shadcn + Tailwind)
* 🧭 Smooth transitions (Framer Motion)
* 🌙 Clean and minimal aesthetic

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/anime-nostalgia-gallery.git
cd anime-nostalgia-gallery
```

---

### 2️⃣ Install Dependencies

```bash
cd anime-nostalgia-gallery
npm install
```

---

### 3️⃣ Run Development Servers

```bash
npm run dev
```
